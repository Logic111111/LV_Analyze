# Test data

Files used by the Feeder Island test scenario (the step-by-step walkthrough of every function).
Import designs on the Designs page with **Import JSON**; paste CSV files into the boxes on the
Field data page.

| File | What it is |
|---|---|
| `walkthrough-island.json` | The golden fixture: one 100 kVA transformer, feeder F1 with poles P1–P3, 18 connections and 2 PV systems. Phase A at P3 is overloaded, so P3 A is 212.9 V at 20:00 (below the 216.2 V limit). Every golden test in `client/src/lib/__tests__` is pinned to it. |
| `two-feeders.json` | Two 12-pole feeders (A1–A12 and B1–B12) from one 100 kVA transformer, meeting at the normally-open point OP1 (A12–B12). Used for the dual-feeder split. Generated by `client/src/lib/__tests__/fixtures/twoFeeders.js` (seed 3). |
| `ami-sample.csv` | One day of 30-minute smart-meter readings for meters M-001 and M-002 (an evening-peak household shape; test data, not real customers). Map M-001 to L1 and M-002 to L2 in the Network page's "Meter id" column first. |
| `field-readings.csv` | Four voltage readings at 20:00 for the walkthrough island. P3 phases B and C are deliberately swapped, so the phase-label check should flag them. |
